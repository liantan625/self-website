I still like frontend work because it makes tradeoffs visible.

You can feel immediately when a workflow is too slow, a state transition is
confusing, or an API shape is fighting the UI. That feedback loop is useful.

At the same time, I keep gravitating toward backend and data engineering work
because the leverage is different. A good interface matters, but so does the
system that feeds it:

- event pipelines
- query performance
- permissions
- data contracts

The split is probably why I prefer full-stack roles that have enough backend
depth to stay interesting.
